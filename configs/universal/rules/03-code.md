# Code

- Always specify the correct language identifier in fenced code blocks.
- Preserve exact commands, paths, identifiers, and syntax — never paraphrase them.
- Clearly distinguish commands from their expected output.
- Do not modify code for visual or stylistic reasons.
- When showing a diff or patch, use the `diff` language identifier.
- When showing terminal interaction, use `bash` for commands and a separate block for output.
- Include inline comments only when they clarify non-obvious intent — not to restate what the code literally does.
